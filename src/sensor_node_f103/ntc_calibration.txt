NTC water-temp sensor calibration reference
============================================

Sensor: 2-wire NTC, ~50 kOhm @ 25 C, beta ~4040 K (fit from the table below).
Measured resistance values, 2026-07-08. This table is the source of the
NTC_TABLE in NtcTemp.h — keep the two in sync.

Divider (as coded in NtcTemp.h):
  3.3 V rail --[ 4.7 kOhm 1% ]--+--> ADC pin (PA4, 12-bit)
                                |
                               NTC
                                |
                               GND
  One sensor wire to board GND, the other to the pin. 100 nF ceramic from
  pin to GND. Twist the sensor pair in the loom.

  R_ntc = 4700 * counts / (4095 - counts)

Counts/volts are computed from the divider formula, not measured.

Fault behaviour (clamped to table ends in ntcTempC):
  open / unplugged sensor -> pin pulled to 3.3 V -> reads 20 C
  shorted sensor          -> 0 V                 -> reads 150 C

Bench check: substitute a fixed resistor for the NTC —
  4.43 kOhm should display 90.0 C, 12.32 kOhm should display 60.0 C.
