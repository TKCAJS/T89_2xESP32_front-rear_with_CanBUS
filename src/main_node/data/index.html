Clutch Voltage Thresholds

Downshift Trigger Voltage

On a downshift request the servo pulls until the feedback voltage passes this threshold, and only then is the DS CAN command sent. Paddle max is the low voltage end, so the trigger fires on the voltage falling past this value.

Just-Engaged (Bite Point) Voltage

Release point for stacked downshifts. Between consecutive shifts the clutch need only come back to the biting point rather than all the way to idle, skipping the dead travel and shortening the stroke. Moving back toward paddle idle raises the voltage, so this sits above the trigger.
